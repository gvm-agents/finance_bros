What is already set up

Tasks

Repeatable work that open models may suit: pull facts from forms, sort and tag items, track news. More mechanical, less open-ended reasoning.

Public data

SEC filings, which come with structured data we can use as an answer key. News feeds, which are messy narrative text.

Standard measures

Accuracy, recall, precision and F1, plus cost, speed, reliability and security. Software marks every answer; no AI grades the results.

Three kinds of model

Frontier for the targets, open models hosted on Fireworks, and small local models on a laptop, to show the tradeoffs.
