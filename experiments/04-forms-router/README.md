# 04 Forms router: rules first, model as fallback

Idea from the team discussion: most Form D facts sit in fixed, structured fields. Read those with plain rules (no model, near zero cost and time) and send only what the rules cannot read to the trained model.

Goal: the same accuracy as 01, at a lower price per 1,000 forms and lower latency. Same 120 test forms, same scorer.

Status: planned.
